

# 📘 销售区域管理中台 - 产品概要设计文档

------

# 一、项目背景

对销售区域进行标准化、统一化管理。目前存在：

- 区域划分不统一
- 系统之间数据不一致
- 缺乏标准化查询能力

因此需要建设一个**销售区域管理中台系统**，作为统一的组织与区域数据源，对上游系统提供标准 API 服务。

------

# 二、建设目标

1. 建立统一的销售组织架构（大区 / 办事处 / 片区）
2. 与国家行政区划（省/市/区/街道）建立映射关系
3. 提供标准查询 API（支持多系统调用）
4. 提供统一鉴权与安全机制
5. 支持高扩展性（未来可扩展渠道、人员等）

## 4.2 组织模型说明

统一使用 organization 表：

| 类型 | 说明   |
| ---- | ------ |
| 1    | 大区   |
| 2    | 办事处 |
| 3    | 片区   |

通过字段实现树结构：

- parent_id：父节点
- path：路径（避免递归）
- level：层级

👉 示例：

```
华南大区（1）
  └ 深圳办事处（2）
       └ 南山片区（3）
```

## 4.3 行政区模型

基于标准四级结构：

- 省-市-区/县-街道/乡镇

通过：

- pid（父级）
- path（完整路径）

实现树形结构。

# 六、核心业务规则

1. **组织层级固定为3级**
   - 大区 → 办事处 → 片区
2. **大区、办事处、片区名称必须唯一**
3. **任意一个省、市、县、区仅且归属一个大区，即仅且归属一个办事处，任何一个乡镇/街道仅且归属一个片区**
4. **大区/办事处关联行政区域到区县级别,片区关联行政区域到乡镇/街道级别**
5. **对于大区/办事处/片区的删除规则**
   - 有子节点不可删除
   - 有绑定关系不可删除

## 7.3 签名机制

### 签名算法说明

采用 MD5 签名算法，确保请求的完整性和不可篡改性。

**签名公式：**

```
sign = MD5(appKey + timestamp + nonce + body + secret)
```

**参数说明：**

| 参数      | 说明                           | 要求                |
| --------- | ------------------------------ | ------------------- |
| appKey    | 调用方标识                     | 由平台分配          |
| timestamp | Unix 时间戳（毫秒）             | 与服务器时间差≤5 分钟 |
| nonce     | 随机字符串（UUID 或 16 位随机数） | 防止重放攻击        |
| body      | 请求体原始 JSON 字符串          | GET 请求为空字符串   |
| secret    | 调用方密钥                     | 由平台分配          |

**签名生成步骤：**

1. 将 `appKey`、`timestamp`、`nonce`、`body`、`secret` 按顺序拼接
2. 对拼接后的字符串进行 MD5 加密
3. 将 MD5 结果转为大写（32 位）

### Java 示例代码

```java
import org.apache.commons.codec.digest.DigestUtils;
import java.util.UUID;

public class ApiSignatureUtil {
    
    private static final String APP_KEY = "your_app_key";
    private static final String SECRET = "your_secret";
    
    /**
     * 生成 API 请求签名
     * @param body 请求体 JSON 字符串，GET 请求传空字符串
     * @return 签名值（大写 32 位）
     */
    public static String generateSignature(String body) {
        long timestamp = System.currentTimeMillis();
        String nonce = UUID.randomUUID().toString().replace("-", "");
        
        // 拼接签名字符串
        String signStr = APP_KEY + timestamp + nonce + body + SECRET;
        
        // MD5 加密并转大写
        return DigestUtils.md5Hex(signStr).toUpperCase();
    }
    
    /**
     * 生成带签名信息的请求头
     * @param body 请求体 JSON 字符串
     * @return 请求头 Map
     */
    public static Map<String, String> generateHeaders(String body) {
        Map<String, String> headers = new HashMap<>();
        headers.put("appKey", APP_KEY);
        headers.put("timestamp", String.valueOf(System.currentTimeMillis()));
        headers.put("nonce", UUID.randomUUID().toString().replace("-", ""));
        headers.put("sign", generateSignature(body));
        return headers;
    }
    
    /**
     * 示例：发起 GET 请求
     */
    public static String get(String url) throws Exception {
        String body = ""; // GET 请求 body 为空
        Map<String, String> headers = generateHeaders(body);
        
        // 使用 HttpClient 或 OkHttp 发起请求
        // ... HTTP 请求代码
        return null;
    }
    
    /**
     * 示例：发起 POST 请求
     */
    public static String post(String url, String jsonBody) throws Exception {
        Map<String, String> headers = generateHeaders(jsonBody);
        headers.put("Content-Type", "application/json");
        
        // 使用 HttpClient 或 OkHttp 发起请求
        // ... HTTP 请求代码
        return null;
    }
}
```
