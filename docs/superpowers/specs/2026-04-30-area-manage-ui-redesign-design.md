# 行政区维护界面改版设计

## 背景

现有行政区维护界面使用单一表格展示4万+条数据，体验差：
- 一次性加载全部数据，性能差
- 树形表格展开/收起操作繁琐
- 新增时需从4万条数据中选择上级行政区
- 搜索功能弱，只能按层级筛选

## 方案

采用 **左侧树形导航 + 右侧列表** 布局（类似文件管理器）。

### 左侧树面板

- `el-tree` 懒加载模式，初始只加载省级节点
- 展开节点时按需加载下一级（到区县级别停止，乡镇通过列表查看）
- 顶部搜索框按名称过滤树节点
- 点击节点选中，右侧显示其子级

### 右侧列表面板

- 面包屑导航显示当前路径（如：北京市 > 市辖区 > 东城区）
- 显示当前选中节点的直接子级列表
- 操作栏：新增、刷新
- 列表列：名称、简称、编码、层级标签、操作（编辑/删除）

### 新增/编辑

- 新增时自动填充 `pid` 为当前选中节点 ID
- 编辑沿用原有对话框，简化字段

### 后端接口

复用现有 `/api/admin/area/tree`，无需新增接口。
